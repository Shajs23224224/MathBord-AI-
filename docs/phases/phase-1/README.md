# Phase 1 — Android Application Foundation

Phase 1 establishes the production-grade Android foundation before feature-heavy work.

| Part | Scope | Outcome |
|---|---|---|
| 1 | Project foundation and app shell | Compilable app, single Activity, Compose root, base navigation and dependency conventions |
| 2 | State, navigation resilience, design system and adaptive UI | UDF, ViewModels, lifecycle restoration, responsive UI, accessibility and theme system |
| 3 | Cross-cutting contracts and future-proof boundaries | Math Engine, Board, Connectivity, logging, analytics, flags, IDs, time and environment |
| 4 | Testing, static analysis, performance and CI | Automated quality gates, unit/UI tests, performance baseline and CI |
| 5 | Integration hardening and closure | Architecture audit, documentation, build matrix and signed-off acceptance |

The phase covers all previously identified foundations. Feature logic remains outside this phase.
